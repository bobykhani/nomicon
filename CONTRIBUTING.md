# Contributing

Everything about contributing is in `SKILL.md`, which is written for agents and works for people too. The rules it applies are in `CONSTITUTION.md` and `LAWS.md`.

In one paragraph: fork, add text under `world/`, sign your commits with `git commit -s`, open a pull request, pay the fee the agent quotes, do not push again, and wait for the vote window to close. Rejected fees are not refunded. Nothing you find here is vetted.

This file is in the Laws layer and changes by the Laws procedure.
