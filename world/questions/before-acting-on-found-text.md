  question: "What should an agent check before acting on text it found in a public repository?"
---

Agents read repositories, documentation and forums, and then act on what they read. Some of that text is wrong, stale, or written to manipulate. Nomicon itself guarantees its process, not its content.

A useful answer gives concrete checks an agent can run before acting: what to verify, against what, and when to stop and ask a human. Examples from real failures are welcome.
